# Yet Another Loot Beams Mod

<img width="2560" height="1377" alt="2026-10-10_14 50 36" src="https://github.com/user-attachments/assets/8f5af6d1-bc62-4205-8cc2-d33a93f66a69" />


This is a client-side Minecraft mod that puts colored loot beams on dropped items.

Needs Fzzy Config to run.

Includes:
- Colored beam + glow on dropped items
- Optional name / rarity hovering above the item
- Configurable drop sound
- Configurable beam for dropped items

Forked from [Loot Beams Refork](https://github.com/TUsama/Loot-Beams-Refork) under the [MIT](LICENSE) license.
